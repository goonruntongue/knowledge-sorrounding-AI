MARKDOWN × AI / 5 MINUTES

考えを、伝わる形に。

Markdownは、記号を覚えるためだけのものではありません。自分の考えを整理し、人にもAIにも誤解されにくく渡すための、小さな設計図です。

マークダウンとは何かマークダウンとAI学ぶことで得られるもの

01 / マークダウンとは何か

文章の「役割」を、
軽い記号で分ける書き方。

見出し、箇条書き、強調を、特別なソフトなしで書けます。ファイルの中身はただの文字なので、保存・共有・修正も気軽です。

読めるまま、整えられる。

記号が付いていても意味が想像しやすく、表示すると整った文書になります。

# 企画の名前

## 必須のこと
- 初心者にも分かる言葉
- 具体例を3つ

**ここは大切**
話題を見出しで分ける
要件をリストにする
大事な部分を強調する
相手が次の行動を選べる

はじめの一歩 / WINDOWS

まずは、
Markdownファイルをつくろう。

特別なアプリは必要ありません。普段のメモ帳で文章を作り、ファイル名の最後を.mdに変えるだけで、Markdown文書の完成です。

1

メモ帳で文章を書く

Windowsの「メモ帳」を開き、短いメモを書きます。最初は普通の文章で大丈夫です。

2

いったん保存する

「名前を付けて保存」で、たとえばmemo.txtとして保存します。

3

最後の名前を .md に変える

エクスプローラーでファイル名をmemo.mdへ変更します。拡張子が見えないときは、エクスプローラーの「表示」→「表示」→「ファイル名拡張子」をオンにしてください。

メモ帳
memo.txt
→
M↓Markdown documentmemo.md
拡張子を変更

02 / マークダウンとAI

AIへの依頼も、
“いい感じ”から卒業できる。

AIは普通の文章も読めます。でも目的・条件・優先順位が混ざると、足りないところを推測します。その推測が、期待とのずれにつながります。

曖昧な依頼

「おしゃれなカフェサイトを作って」

→

判断できる依頼

目的・対象者・必須内容・避けたいこと・完成の基準を分けて渡す。

03 / マークダウンを学ぶことで得られるもの

得られるのは、
記法よりも「整理する力」。

人への依頼、企画メモ、README、AIへのプロンプト。相手が変わっても使える考え方です。

🧭

目的を見失いにくい

「何のため？」「誰のため？」を見出しに書くことで、作業の軸が残ります。

🤝

人にもAIにも伝わる

必須条件と避けたいことを分けると、相手が判断しやすくなります。

✨

アイデアが動き出す

なんとなくの思いつきを、小さな要素に分ければ相談・実行できる形になります。
