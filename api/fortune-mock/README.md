# 誕生月のおたより：API体験モック

教材本体へはまだ組み込んでいない、独立した試作です。

## 起動

このフォルダで次を実行します。Node.js以外の追加パッケージは不要です。

```powershell
node server.js
```

ブラウザで http://localhost:4178/ を開きます。終了はターミナルで Ctrl+C。
4178番が使用中なら環境変数 `FORTUNE_PORT` で別の番号を指定できます。
サーバーは自分のPCだけで接続できる設定です。

## データと接続先

- `fortune.json`：月をキーにした配列。12か月×5件＝60件。
- 各件は `id` / `message` / `image` / `alt` の組。画像は個別の透過PNG。
- `GET /fortune.api?month=1`：1月の5件からサーバーが1件を抽選しJSONを返す。
- `exclude=01-01`：直前のIDを抽選候補から外す（任意）。
- `/fortune.api` はファイルの拡張子ではなく、この試作サーバーが処理するエンドポイント。
- 誕生月や履歴は保存しない。直前の抽選結果だけをブラウザのメモリーに保持。
- ブラウザでJSONのエンドポイントを直接開くと新しく抽選する。画面のJSON欄はカードと同じ結果。

## モード

Nodeサーバーでは実API通信。静的ホストでは `fortune.json` を取得してブラウザ内で抽選し、その旨を表示します。
`index.html` を直接開いた場合は `fortune.json` をファイル選択して通信なしで見た目を試せます。この場合もAPI通信と区別して表示します。

## 画像

`sprites/` に生成した原本シートとプロンプト、`images/` に60枚の個別PNG。
切り出しは safe-character-sprites のルール（各画像1体、背景透過、10%以上の余白、隣接画像の断片除外）に沿って行います。
`sprite-gallery.html` でコメントと画像の対応を確認できます。

生成は内蔵の画像生成ツールを使用。15体×4シートを生成し、各被写体の連結した輪郭を個別に抽出しました。
元シートに含まれた微小な透過ノイズを除き、輪郭のアンチエイリアスを保持して切り出しています。
最終画像は512×512、四辺の透過余白は最低64px（12.5%）です。

## 確認済み（2026年10月5日）

- 12か月×5件、メッセージ60件、異なる画像60枚の対応。
- 全60枚の輪郭・手足・持ち物を目視確認。切れや隣接被写体の写り込みなし。
- 全PNGの背景透過、四辺の余白、不要な独立断片がないことを数値検査。
- 全12か月のAPI応答、直前のIDを除く再抽選、不正な月は400、GET以外は405。
- ソースファイルを公開しないこと、および60枚の画像がHTTPで取得できること。
- ブラウザで選択・抽選、画像・コメント・JSONの一致、画像一覧の60件表示。
- 1280px / 390px / 320px幅で横にはみ出さないこと。ブラウザ実行エラーなし。
