Renderに繋ぐ場合のポイントをCodexでまとめました。

初回はGitHub連携の許可画面が出ます。Renderが自分のリポジトリ一覧を読めるようにするための接続です。

Render画面の用語
- Project：複数のサービスをまとめて見やすくする「フォルダ」のようなもの。任意です。
- Web Service：Node.js／Expressを実際に起動して、Web APIを公開する本体です。今回必要なのはこちらです。

今回の小さなAPIでは、Projectを作らなくて大丈夫です。
Renderでは + New → Web Service

githubのリポジトリを選択する（Create Projectは今回は押す必要はない）

New Web Service欄

無料プランを選ぶ
Compute欄の一番上、$0 / month / Free の行の左にある丸い選択ボタンをクリックしてください。
Build Command の欄にある yarn install を、次の文字列へ完全に置き換えてください。
目的：package.json に書いたExpressを、Render上へインストールする

Start Command の node server.js を、次の文字列へ完全に置き換えてください。
npm start は、リポジトリ内の package.json に書いた次の設定を実行します。
"start": "node server.js"


設定は以下の通りです。
項目	設定値
Build Command	npm install
Start Command	npm start
Compute	$0 / month Free
Root Directory	空欄
Branch	main
