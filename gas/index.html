01 / GASとは

GASは、Googleサービスを動かすJavaScript。

Google Apps Script（GAS、ガス）は、Googleのサービスを操作するためのプログラムを書いて動かすしくみです。書き方はJavaScriptと同じで、Googleアカウントがあれば、ブラウザーだけで始められます。

書く場所

ブラウザーのエディタ

インストールは要りません。スプレッドシートやドキュメントの「拡張機能」→「Apps Script」から、専用のエディタが開きます。

動く場所

Googleのサーバー

書いたコードは自分のPCではなく、Googleのサーバーで動きます。PCを閉じていても、決まった時刻に動かすこともできます。

つなげる相手

Googleのサービス

スプレッドシート、ドキュメント、カレンダー、Gmail、ドライブなど。SpreadsheetApp や CalendarApp のような名前の道具で操作します。

このページで作るもの

  1. ドキュメントにメニューを足して、雛形を右側のフォームから埋める
  2. カレンダーの予定をスプレッドシートへ読み込む・書き出す
  3. スプレッドシートをWeb APIにして、HTMLの画面とつなぐ

02 / 2つの型

ファイルにくっつけるか、
単独で置くか。

GASのプログラム（プロジェクト）には、置き方が2種類あります。どちらも書き方は同じで、違うのは「どこから作るか」と「親になるファイルがあるか」です。

CONTAINER-BOUND

コンテナバインド型

スプレッドシートやドキュメントなど、1つのファイル（コンテナ）にくっついたスクリプトです。そのファイルを開き、「拡張機能」→「Apps Script」で作ります。

STANDALONE

スタンドアロン型

どのファイルにもくっつかず、ドライブに単独で置くスクリプトです。script.google.com で新しいプロジェクトを作るか、ドライブの「新規」→「その他」→「Google Apps Script」で作ります。

くらべる点コンテナバインド型スタンドアロン型
ドライブでの見え方ドライブには出てこない。親ファイルから開く1つのファイルとしてドライブに並ぶ
親ファイルの操作getActiveSpreadsheet() などで、IDを書かずに親ファイルを扱える親がないので、openById() などでIDを指定して開く
メニュー・ダイアログgetUi() で、親ファイルの画面にメニューやダイアログを足せるファイルの画面にメニューは足せない
ウェブアプリにするできるできる
向いている用途「このシート専用」「この文書専用」の便利機能複数のファイルをまたぐ処理、ドライブの整理などの道具

覚えておくこと：コンテナバインド型は、あとから親ファイルと切り離せません。このページの作例は、すべてコンテナバインド型で作ります。

03 / 最初の実行と承認

初めて動かすときは、
権限の承認が出る。

GASが自分のドキュメントやカレンダーを操作するには、あなたの許可が必要です。初めて実行したとき（使う道具が増えたときも）に、承認を求める画面が続けて出ます。

実際のGoogle Apps Scriptで撮影しました（2026年10月24日）。個人情報は加工して隠しています。一部の画像では操作・確認する箇所を赤枠で示しています。画像を押すと大きく表示できます。

  1. 承認が必要です

    初めて関数を実行すると、この案内が出ます。「権限を確認」を押して、Googleの承認画面へ進みます。

  2. 未確認アプリの警告を確認する

    「このアプリは Google で確認されていません」と出ることがあります。自分で作り、内容を理解したスクリプトであることを確認して「詳細」を開きます。

  3. 自分のスクリプトであることを確認して進む

    「詳細」を開くと、プロジェクトへの移動リンクが現れます。名前と内容を確認し、信頼できる自分のスクリプトの場合だけ進みます。

  4. 求められる権限を確認する

    アプリ名と、何を見たり変えたりできるようになるかを読みます。必要な権限だと納得した場合だけ、画面の案内に沿って承認します。表示される権限やボタン名は、コードやアカウントによって変わります。

安全メモ：警告を進めてよいのは、自分で書いた、または中身を理解したスクリプトだけです。人から渡されたスクリプトや、知らない人のファイルに入っていたスクリプトは、権限の一覧を見て、むやみに許可しないでください。

途中でアカウント選択画面が表示された場合は、使用するGoogleアカウントを選びます。今回の撮影ではこの選択は省略されました。画面の文言や順番は、Googleの画面の更新で変わることがあります。練習画面では、この流れを簡略化して再現しています。

ドキュメントの雛形を、
右側のフォームから埋める。

案内文やお礼状の書式はドキュメントで作り、変わる部分だけを {名前}・{日付}・{内容} にしておきます。メニューから右側の入力パネルを開き、入力した値を文書に差し込みます。

  3. スクリプトを追加1：Code.gs（日本語表示では「コード.gs」）に、下の「Code.gs」のコードを貼ります。最初から入っているコードは、すべて置き換えます。

function fillTemplate(data) {
  const values = {'名前': String(data.name || '').trim(), '日付': String(data.date || '').trim(), '内容': String(data.content || '').trim()};
  if (Object.values(values).some(value => !value)) throw new Error('すべての欄を入力してください。');
  const lock = LockService.getDocumentLock();
  lock.waitLock(10000);
  try {
    const body = DocumentApp.getActiveDocument().getActiveTab().asDocumentTab().getBody();
    const changes = [], found = new Set();
    const pattern = '\\{(名前|日付|内容)\\}';
    let match = body.findText(pattern);
    while (match) {
      const text = match.getElement().asText();
      const start = match.getStartOffset(), end = match.getEndOffsetInclusive();
      const key = text.getText().slice(start + 1, end);
      changes.push({text, start, end, value: values[key]});
      found.add(key);
      match = body.findText(pattern, match);
    }
    if (found.size !== 3) throw new Error('本文に {名前}・{日付}・{内容} をそろえてください。差し込み済みなら元の雛形をコピーし直します。');
    changes.reverse().forEach(c => {
      c.text.insertText(c.start, c.value);
      c.text.deleteText(c.start + c.value.length, c.end + c.value.length);
    });
    return '差し込みました。文書を確認してください。';
  } finally { lock.releaseLock(); }
}

プレースホルダーの置き換え
本文の目印だけを入力値に置き換え、周囲の文面やレイアウトを残します。入力値に記号が含まれていても、そのまま文字として差し込みます。

使うたびに雛形をコピー：差し込むと目印は入力値に変わります。別の文書を作るときは元の雛形からコピーしてください。この例は現在開いているタブの本文（表の中も含む）が対象です。ヘッダー・フッター・他のタブは対象にしていません。各目印は途中で改行せず、ひと続きの文字として書きます。

05 / カレンダー ⇄ スプレッドシート

カレンダーの予定を、
シートに読み込む・書き出す。

スプレッドシートのメニューから、カレンダーの予定を一覧にしたり、シートに書いた予定をまとめてカレンダーに登録したりします。

1

カレンダーを選ぶ

右側のパネルに、実行アカウントが所有・登録しているカレンダーを表示します。読み込み用と書き込み用を、それぞれ名前で選んで保存します。IDの手入力は不要です。

2

予定を読み込む

getEvents(開始, 終了) で期間内の予定をまとめて取り出し、1件1行でタイトル・日時・場所をシートに書き込みます。

3

予定を書き出す

シートの行を上から順に読み、予定IDが空の行をすべて createEvent() で登録します。作った予定のIDを各行に書き戻します。

読み込みも書き出しも、何行でもまとめて：読み込みは、今日から30日分の予定をすべて「読み込み」シートに1件1行で並べます。書き出しは、「書き出し」シートで予定IDが空の行をすべて、上から順に登録します。1行ずつ実行し直す必要はありません。

実際の画面で試す

教材用のシートとカレンダーで実行・撮影しました（2026年10月24日）。緑の角丸枠が操作・確認する場所です。画像は押すと拡大でき、上の「元の画面に戻る」で閉じられます。

  2. 2つのコードを保存する：下の2-calendar-sheet/Code.gs のコードを、最初からあるコードとすべて置き換えて保存します。続いて左の「＋」→「HTML」で名前を CalendarSettings にし、下のCalendarSettings.html のコードをすべて貼り、保存します。拡張子の .html は自動で付きます。
  3. 選択パネルを開く：シートを開き直し、「カレンダー連携」→「カレンダーを選ぶ」を選びます。承認後にパネルが開かなければ、同じメニューを選び直します。
  4. 必要な権限を確認する：初回に承認が表示されたら、03節の手順でアプリ名と権限を確認します。この例ではスプレッドシートとカレンダーへのアクセス、シート内にパネルを表示する権限を使用します。ご自身のコードと照らし合わせ、必要な権限を選んで承認します。撮影時とアプリ名や画面の順番が異なる場合があります。
  5. 読み込み用・書き込み用を選ぶ：右側パネルの2つの一覧から、それぞれのカレンダーを選び、「この組み合わせを保存」を押します。同じカレンダーでも、別々のカレンダーでも構いません。最初は練習用カレンダーを選びます。このパネルはGoogleアカウントを切り替えるものではありません。実行アカウントが所有・登録しているカレンダーが対象で、共有カレンダーへの書き込みには編集権限が必要です。選択内容はこのスクリプトの利用者ごとに保存されます。
  6. 予定を書き出す（何行でもまとめて）：「書き出し」の1行目を「タイトル・開始・終了・場所・予定ID・終日」にし、2行目から予定を1件1行で入力します。開始と終了は日時として入力し、予定IDは空欄にします。「カレンダー連携」→「予定をカレンダーへ書き出す」を選ぶと、予定IDが空の行をすべて、パネルで選んだ書き込み先にまとめて登録します。この例では、登録済みの1行目に3行を書き足してから実行しました。

  9. 予定を読み戻す（期間内をすべて）：「カレンダー連携」→「予定を読み込む（今日から30日分）」を選びます。読み込み先カレンダーの今日から30日分の予定がすべて、1件1行で「読み込み」シートに並びます。シートの内容は毎回置き換わります。開始・終了は日時の形式で表示します。

// 現在の実行アカウントが所有・登録しているカレンダーを取得する。
function getCalendarSettings() {
  const props = PropertiesService.getUserProperties();
  return {
    calendars: CalendarApp.getAllCalendars().map(cal => ({
      id: cal.getId(), name: cal.getName(), owned: cal.isOwnedByMe()
    })),
    importId: props.getProperty('importCalendarId') || '',
    exportId: props.getProperty('exportCalendarId') || ''
  };
}

function saveCalendarSettings(importId, exportId) {
  const ids = CalendarApp.getAllCalendars().map(cal => cal.getId());
  if (!ids.includes(importId) || !ids.includes(exportId)) {
    throw new Error('両方のカレンダーを一覧から選んでください。');
  }
  PropertiesService.getUserProperties().setProperties({
    importCalendarId: importId, exportCalendarId: exportId
  });
  return '保存しました。メニューから読み込み・書き出しを実行できます。';
}

function selectedCalendar_(key) {
  const id = PropertiesService.getUserProperties().getProperty(key);
  if (!id) throw new Error('先に「カレンダー連携」→「カレンダーを選ぶ」で保存してください。');
  const calendar = CalendarApp.getCalendarById(id);
  if (!calendar) throw new Error('選択したカレンダーにアクセスできません。選び直してください。');
  return calendar;
}

// カレンダー → 「読み込み」シート。今日の0時から30日分。
function importEvents() {
  const calendar = selectedCalendar_('importCalendarId');
  const start = new Date();
  start.setHours(0, 0, 0, 0);
  const end = new Date(start);
  end.setDate(end.getDate() + 30);
  const rows = calendar.getEvents(start, end).map(ev => [
    ev.getTitle(), ev.getStartTime(), ev.getEndTime(), ev.getLocation(),
    ev.isAllDayEvent() ? '終日' : ''
  ]);
  const book = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = book.getSheetByName('読み込み') || book.insertSheet('読み込み');
  sheet.clearContents();
  sheet.appendRow(['タイトル', '開始', '終了', '場所', '終日']);
  if (rows.length) {
    sheet.getRange(2, 1, rows.length, 5).setValues(rows);
    sheet.getRange(2, 2, rows.length, 2).setNumberFormat('yyyy/mm/dd hh:mm');
  }
  book.setActiveSheet(sheet);
  book.toast(rows.length + '件を読み込みました。', 'カレンダー連携');
}

function isDate_(value) {
  return value instanceof Date && !isNaN(value.getTime());
}

// 「書き出し」シート → カレンダー。予定IDがある行は再登録しない。
// 列：タイトル | 開始 | 終了 | 場所 | 予定ID | 終日
// 「終日」の列に「終日」と書いた行は終日の予定にする。終了日を入れると、その日までの連日の予定になる。
function exportEvents() {
  const lock = LockService.getDocumentLock();
  if (!lock.tryLock(5000)) throw new Error('処理中です。少し待ってから実行してください。');
  try {
    const calendar = selectedCalendar_('exportCalendarId');
    const book = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = book.getSheetByName('書き出し');
    if (!sheet) throw new Error('「書き出し」シートを作り、予定を入力してください。');
    const values = sheet.getDataRange().getValues();
    for (let i = 1; i < values.length; i++) {
      const [title, start, end, , eventId, allDay] = values[i];
      if (!title || eventId) continue;
      if (String(allDay).trim() === '終日') {
        if (!isDate_(start) || (end !== '' && (!isDate_(end) || end < start))) {
          throw new Error((i + 1) + '行目の開始を日付で入力し、終了日を入れるときは開始日以降にしてください。');
        }
      } else if (!isDate_(start) || !isDate_(end) || end <= start) {
        throw new Error((i + 1) + '行目の開始・終了を日時で入力し、終了を開始より後にしてください。');
      }
    }
    let count = 0;
    for (let i = 1; i < values.length; i++) {
      const [title, start, end, location, eventId, allDay] = values[i];
      if (!title || eventId) continue;
      const options = { location: String(location || '') };
      let ev;
      try {
        if (String(allDay).trim() === '終日') {
          // カレンダーの終日予定は「最終日の翌日」で終わるため、1日足して渡す
          const startDay = new Date(start.getFullYear(), start.getMonth(), start.getDate());
          const lastDay = isDate_(end) ? new Date(end.getFullYear(), end.getMonth(), end.getDate()) : startDay;
          const endDay = new Date(lastDay);
          endDay.setDate(endDay.getDate() + 1);
          ev = calendar.createAllDayEvent(String(title), startDay, endDay, options);
        } else {
          ev = calendar.createEvent(String(title), start, end, options);
        }
      } catch (error) {
        throw new Error((i + 1) + '行目を書き出せませんでした。書き込み権限を確認してください。詳細: ' + error.message);
      }
      sheet.getRange(i + 1, 5).setValue(ev.getId());
      SpreadsheetApp.flush();
      count++;
    }
    book.toast(count + '件を書き出しました。予定IDがある行はスキップします。', 'カレンダー連携');
  } finally {
    lock.releaseLock();
  }
}

  const data = JSON.parse(e.postData.contents);

  const name = clean(data.name, 40);

// = + - @ で始まる値は、数式にならないよう ' を付ける
function clean(value, max) {
  const text = String(value || '').trim().slice(0, max);
  return /^[=+\-@]/.test(text) ? "'" + text : text;
}

    09 / 公開するときの注意

    動いたあとに、
    確かめておくこと。

    1

    URLを知っていれば使える

    「全員」に公開すると、URLを知っている人は誰でもAPIを呼べます。名前やメールアドレスなどの個人情報は、返すデータに入れないでください。

    2

    直したら、デプロイし直す

    公開中のURLは、デプロイしたときのバージョンで動きます。コードを直したら「デプロイ」→「デプロイを管理」→ 編集で新しいバージョンを選ぶと、同じURLのまま更新できます。

    3

    使える量には上限がある

    無料のGoogleアカウントでは、1回の実行は6分まで、カレンダーの予定作成は1日5,000件まで、などの上限があります。上限は変わることがあるので、公式資料で確かめてください。

    4

    テスト用のURLもある

    「デプロイをテスト」の /dev で終わるURLは、編集できる人だけが開け、保存した最新のコードで動きます。人に渡すのは /exec のURLです。
