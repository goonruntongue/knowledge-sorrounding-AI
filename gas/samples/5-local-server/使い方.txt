ローカルサーバー 使い方
==============================

これは何？
  作例A（お知らせ一覧）と作例B（出欠フォーム）の HTML は、
  ブラウザーから GAS のウェブアプリを呼び出します。
  HTML ファイルをダブルクリックで直接開くと、ブラウザーの安全のしくみによって
  読み込みや送信に失敗することがあります。
  そこで、自分のパソコンの中に小さな Web サーバー（ローカルサーバー）を立てて、
  http://localhost:8000/ というアドレスで開きます。

  このサーバーは、自分のパソコンの中からしか見られません。
  ほかの人のパソコンやスマホからは見えないので、安心して試せます。
  追加のソフトのインストールはいりません。
    Windows … 最初から入っている PowerShell で動きます
    Mac     … 最初から入っている Python 3 で動きます

  ほかの方法として、自分が契約しているレンタルサーバーなどに
  HTML ファイルをアップロードして開いても動きます。


このフォルダーの中身
  使い方.txt                     いま読んでいるファイル
  サーバーを起動（Windows）.bat   Windows でサーバーを起動する
  サーバーを起動（Mac）.command   Mac でサーバーを起動する
  ここにHTMLを置く\              自分の HTML を置くフォルダー
      index.html                 入口のページ（下の2つへのリンク）
      notice.html                作例A：お知らせ一覧
      attendance.html            作例B：出欠フォーム
  tools\
      local-server.ps1           Windows 用のサーバーの中身（触らなくて大丈夫です）


準備：ウェブアプリの URL を HTML に書き込む
  1. GAS で作例をデプロイし、表示された「ウェブアプリ URL」（/exec で終わる）をコピーします。
  2. 「ここにHTMLを置く」フォルダーの notice.html（作例B なら attendance.html）を
     メモ帳（Mac はテキストエディット）で開きます。
     Mac のテキストエディットでは、「フォーマット」→「標準テキストにする」になっているか確かめます。
  3. const API_URL = ''; の '' の中に、コピーした URL を貼り付けて保存します。
       例） const API_URL = 'https://script.google.com/macros/s/…/exec';


Windows での使い方
  1. ZIP を右クリック →「すべて展開」で、フォルダーに取り出します。
     （ZIP の中から直接ダブルクリックしても動きません）
  2. 「サーバーを起動（Windows）.bat」をダブルクリックします。
     ・「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。
     ・「発行元を確認できませんでした」と出たら、「実行」を押します。
  3. 黒い画面が開き、ブラウザーで http://localhost:8000/ が開きます。
     開かないときは、ブラウザーのアドレス欄に http://localhost:8000/ と入力します。
  4. 終わったら、黒い画面を閉じます。これでサーバーが止まります。


Mac での使い方
  1. ダウンロードした ZIP をダブルクリックして、フォルダーに取り出します。
  2. 「アプリケーション」→「ユーティリティ」→「ターミナル」を開きます。
  3. ターミナルに bash と半角スペースを入力し、
     「サーバーを起動（Mac）.command」をターミナルの画面にドラッグして、return キーを押します。
     （ファイルをダブルクリックすると「開発元を確認できない」と止められることがあるため、
       この方法をおすすめします）
  4. 少しするとブラウザーで http://localhost:8000/ が開きます。
     開かないときは、ブラウザーのアドレス欄に http://localhost:8000/ と入力します。
  5. 終わったら、ターミナルで control キーを押しながら C を押し、ウィンドウを閉じます。

  「コマンドライン・デベロッパ・ツール」のインストールを求められたら、
  案内に従ってインストールしてから、もう一度 3. を行います。


自分の HTML を置くとき
  「ここにHTMLを置く」フォルダーに、HTML ファイル（画像や CSS も）を入れます。
  たとえば mypage.html を置いたら、http://localhost:8000/mypage.html で開けます。
  ファイルを直したら、ブラウザーを再読み込みします。サーバーの再起動はいりません。
  Windows では、アドレスを localhost と書きます（127.0.0.1 では開けません）。


うまくいかないとき
  ・黒い画面に「8000 番でサーバーを起動できませんでした」と出る
      ほかのソフトが 8000 番を使っています。そのソフトを閉じるか、
      パソコンを再起動してから、もう一度試します。
  ・黒い画面がすぐ閉じる
      会社などのパソコンで、PowerShell の利用が止められている場合があります。
      その場合は、レンタルサーバーなどに HTML を置いて試します。
  ・お知らせが出ない、送信できない
      API_URL に貼った URL と、デプロイの「アクセスできるユーザー」の設定を確かめます。
      GAS のコードを直したときは、デプロイし直さないと URL に反映されません。


注意
  ・使い終わったら、サーバーを止めます。
  ・Web サーバーとして公開されるのは「ここにHTMLを置く」フォルダーの中だけです。
    それ以外のフォルダーのファイルは見られません。
