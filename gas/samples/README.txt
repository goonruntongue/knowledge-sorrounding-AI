GAS でGoogleサービスをつなぐ ― サンプル一式

このフォルダーの中身
  1-report-template/Code.gs     Google ドキュメントの雛形を、右側のフォームから埋める
  1-report-template/Sidebar.html 入力フォーム（HTMLファイル名は Sidebar）
  2-calendar-sheet/Code.gs      カレンダーの予定をスプレッドシートへ読み込む／シートの予定をカレンダーへ書き出す
  2-calendar-sheet/CalendarSettings.html カレンダー選択パネル（HTMLファイル名は CalendarSettings）
  3-notice-api/Code.gs          作例 A: お知らせ一覧を JSON で返すウェブアプリ（GET）
  3-notice-api/index.html       作例 A の画面。API_URL にウェブアプリの URL を入れて開く
  4-attendance-api/Code.gs      作例 B: 出欠をシートに書き込むウェブアプリ（POST）
  4-attendance-api/index.html   作例 B の画面。API_URL にウェブアプリの URL を入れて開く

使い方
  .gs のファイルは、Google ドキュメントまたはスプレッドシートの
  「拡張機能」→「Apps Script」で開いたエディタに貼り付けて保存します。
  各ファイルの先頭に、準備することを書いています。

注意
  - 初めて実行するときは、権限の承認を求める画面が出ます。表示される権限の内容を読んでから許可してください。
  - ウェブアプリを「全員」に公開すると、URL を知っている人は誰でも使えます。個人情報をシートに置かないでください。
  - コードを直したら、「デプロイ」→「デプロイを管理」から新しいバージョンでデプロイし直すまで、公開中の URL には反映されません。

ドキュメントの差し込みフォーム
  本文に {名前}様、{日付}、{内容} を用意します。
  Code.gs と HTML ファイル Sidebar を同じプロジェクトに保存します。
  文書を開き直し、作業用コピーで「差し込み」→「入力フォームを開く」。
  初回の権限を確認して承認し、必要ならメニューを選び直します。
  差し込み後は目印がなくなるため、次回は元の雛形をコピーします。
  現在のタブの本文のみが対象です。ウェブアプリのデプロイは不要です。

カレンダー連携
  使うGoogleアカウントでシートを開き、「読み込み」「書き出し」の2枚を作ります。
  Code.gs と HTML ファイル CalendarSettings を同じプロジェクトに保存します。
  シートを開き直し、「カレンダー連携」→「カレンダーを選ぶ」。
  初回の権限を確認して承認し、必要ならメニューを選び直します。
  読み込む・書き込むカレンダーを名前で選んで保存します。IDの手入力は不要です。
  このパネルでGoogleアカウントは切り替えません。実行アカウントが所有・登録するカレンダーが対象です。
  共有・登録カレンダーへの書き込みには編集権限が必要です。最初は練習用を使います。
  設定はこのスクリプトの利用者ごとに保存します。ウェブアプリのデプロイは不要です。
  書き出しの1行目：タイトル、開始、終了、場所、予定ID。開始・終了は日時で入力します。
  予定IDが入った行は再登録しません。読み込みは「読み込み」シートを置き換えます。
