02 / INSTALL

公式サイトから、はじめよう。

Windowsの場合も、最初はアプリのインストールから。アカウントやプラン、組織の設定によって利用できる機能は異なります。

ChatGPT / Codex

  1. ChatGPTの公式ダウンロードを開き、Windows用を選ぶ。
  2. 案内に従ってインストールし、ChatGPTアカウントでログイン。
  3. アプリの切り替えメニューからCodexを選ぶ。

旧版のChatGPT Classicとは表示や機能が異なります。

Claude / Claude Code

  1. Claudeの公式ダウンロードで、PCに合うWindows用を選ぶ。
  2. インストール後、Claudeアカウントでログイン。
  3. Code（</>）タブを選ぶ。追加セットアップが表示されたら案内に従う。

Google Antigravity

  1. Antigravityの公式ダウンロードを開く。
  2. Antigravity 2.0のWindows用から、PCに合う版をインストール。
  3. アプリの案内に従ってGoogleアカウントでログインし、プロジェクトを作る。

IDE版もあります。ここで紹介しているのはエージェント管理用の2.0です。

03 / CODEX

作業場所と、任せる範囲を決める。

まずは作品フォルダを選択

Codexに切り替え、プロジェクト追加やフォルダ選択から、自分の作品フォルダを開きます。新しいタスクを作成し、そのフォルダが作業場所になっていることを確認します。

my-website/
├─ index.html
└─ css/
   └─ style.css

フォルダの選択は「どの作品を扱うか」の指定です。権限の選択は「どこまで操作を任せるか」の指定です。

承認を求める

作業領域内の読み書きや通常のコマンドは進められます。領域外へのアクセスやネットワーク利用など、境界を越える操作で承認を求めます。

代わりに承認

対象となる承認依頼を、レビュー用のエージェントが判断します。依頼内容や許可範囲を確認する仕組みで、すべての操作を無条件に許可する意味ではありません。

フルアクセス

ファイルやネットワークへの制限を広く解除します。何にアクセスする作業かを理解して選びましょう。初回の教材では「承認を求める」で練習できます。

04 / CLAUDE CODE

Codeタブから、作品につなぐ。

ローカル → フォルダ → 依頼

上部の</>（Code）へ切り替え、入力欄の上でローカルとフォルダを指定します。ローカルは自分のPCで作業するという意味です。

✳ Claude </> Code
何をつくりましょう？
▱ ローカル　 ▱ my-website
やってほしいことを入力…
＋　権限：プラン ▾

自動（Auto）

依頼との整合性をバックグラウンドでチェックし、承認の手間を減らします。利用条件や組織の設定によって表示されないことがあります。

編集を受け入れる（Accept edits）

ファイル編集や一部の基本的なファイル操作を自動承認します。それ以外のコマンドでは承認を求めることがあります。

プラン（Plan）

ファイルを調べて作業計画を提案します。ソースコードは編集しません。計画を確認したら編集可能なモードへ切り替えて実行します。

一つずつ自分で承認したい場合は、手動（Manual）も選べます。画面の名称や配置は、アプリの更新・OS・言語設定で変わることがあります。

05 / WORK TOGETHER

「何を、どう変えるか」を伝えよう。

そのまま試せる依頼文

# 目的
トップページの見出しを変えたいです。

# 変更内容
index.htmlのh1を
「はじめてのAI制作」にしてください。

# 条件
ほかの文章やレイアウトは変えないでください。
変更後に、変更箇所と確認結果を教えてください。
01　変更点を読む

完了メッセージだけでなく、差分（変更前と変更後）とブラウザ表示を確認します。

02　途中でも指示を直せる

意図がずれたら停止して、「色はそのままで」と具体的に補足しましょう。

03　Gitで区切りを残す

作業前後に変更を確認してコミット。AIの編集も、履歴があれば比較しやすくなります。
