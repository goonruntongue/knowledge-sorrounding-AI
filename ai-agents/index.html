02 / INSTALL

公式サイトから、はじめよう。

Windowsの場合も、最初はアプリのインストールから。アカウントやプラン、組織の設定によって利用できる機能は異なります。

ChatGPT / Codex

  1. ChatGPTの公式ダウンロードを開き、Windows用を選ぶ。
  2. 案内に従ってインストールし、ChatGPTアカウントでログイン。
  3. アプリの切り替えメニューからCodexを選ぶ。

旧版のChatGPT Classicとは表示や機能が異なります。

Claude / Claude Code

  1. Claudeの公式ダウンロードで、PCに合うWindows用を選ぶ。
  2. インストール後、Claudeアカウントでログイン。
  3. Code（</>）タブを選ぶ。追加セットアップが表示されたら案内に従う。

Google Antigravity

  1. Antigravityの公式ダウンロードを開く。
  2. Antigravity 2.0のWindows用から、PCに合う版をインストール。
  3. アプリの案内に従ってGoogleアカウントでログインし、プロジェクトを作る。

IDE版もあります。ここで紹介しているのはエージェント管理用の2.0です。

EXAMPLE: CHATGPT

ここからは、例として ChatGPT の使い方を紹介します。AIエージェントにはさまざまな製品がありますが、このページでは ChatGPT デスクトップアプリ（Chat / Work / Codex）を取り上げ、モードの選び方、スキルとプラグイン、開発用の Codex を順に見ていきます。

Claude Code や Antigravity でも、「作業フォルダを選ぶ → 任せる範囲を決める → 依頼する → 変更を確認する」という流れは共通です。画面の名前や配置は製品ごとに異なるので、使うときはそれぞれの公式資料で確認しましょう。

03 / CHATGPT APP

相談する。仕上げる。開発する。

同じChatGPTアプリでも、目的に合わせて入口を選べます。まずは「何を受け取りたいか」で考えましょう。

CHAT

会話で考えを進める

質問、アイデア出し、文章の下書き、比較や相談に。

「文化祭サイトの見出し案を3つ出して」

受け取る例：説明・候補・下書き

WORK

成果物まで仕上げてもらう

調査・分析・資料作成など、複数の手順がある仕事を依頼します。

「文化祭サイトの企画書を、確認できる資料にまとめて」

受け取る例：企画書・表・スライド

CODEX

開発の中身を見ながら進める

ファイル編集、差分の確認、テストなど、ソフトウェア開発に適した画面です。

「index.htmlの見出しを変えて、表示を確認して」

受け取る例：コードの変更・確認結果

ChatGPT ▾Chat ↔ Work
Codex ▾プロジェクト・ファイル・差分

アプリの製品切り替えからChatGPT / Codexを選び、ChatGPT側でChat / Workを切り替えます。WorkとCodexは作業能力が重なります。Workでもコードを扱え、Codexでも資料を作れます。「得意な入口と見せ方」の違いです。

使える機能はアカウント・実行環境・設定によって異なります。公式：Chat・Work・Codexの使い分け

04 / SKILLS & PLUGINS

いつもの手順と、使える道具を増やす。

SKILL

スキル＝作業のレシピ

「どんな順番で、何を確認して、どんな形に仕上げるか」を再利用する仕組み。指示・参考資料・必要に応じたスクリプトをまとめます。

例：文章を「目的 → 対象 → 依頼内容」の順に整理する。

中心になるのはSKILL.mdという指示ファイルです。スキルだけで外部サービスのアカウントに接続できるわけではありません。

PLUGIN

プラグイン＝追加機能のパッケージ

スキルや、外部サービスにつながる道具などをまとめてインストールする仕組み。スキルだけを含むものもあります。

例：GitHubの情報を調べる道具と、作業手順を追加する。

必要な場合は外部アカウントを接続します。インストール・接続・依頼はそれぞれ別の操作です。

スキルを導入する

  1. Customizeを開く：左端のアイコン列からCustomizeを開き、Skillsを選びます。
  2. 追加を押す：右上の追加を押すと、Skill Creatorが呼び出された新しいチャットが開きます。覚えてほしい手順を説明して送信します（チャット欄で@skill-creator、Codexでは$skill-creatorと呼ぶこともできます）。
  3. 登録を確認：Skills一覧の「インストール済み」で内容と適用範囲を確認します。見つからない場合はアプリを再起動して確認します。
  4. 既存のものを追加：配布されたスキルは、Codexで$skill-installerを呼び、スキル名や配布元のURLを伝えて導入できます。
Skill Creator
「依頼文整理」というスキルを作って。
このプロジェクトの依頼文を
目的・対象ファイル・変更内容・条件に整理して。

練習では、配布されたスキルを入れる方法と、自分用に作る方法を選べます。配布元から導入する場合も内容を確認しましょう。公式：スキルの作成・導入

プラグインを導入する

  1. Pluginsを開く：左端のアイコン列からCustomizeを開き、Pluginsを選びます。一覧や検索で目的のプラグインを探します。
  2. ＋で追加：説明と含まれる機能を確認して、行の右端の＋から追加します。追加済みのものは「…」になり、左の「Installed」に並びます。
  3. 必要なら接続：外部サービスへのログインとアクセス範囲を確認します。最初の利用時に求められる場合もあります。
  4. @ で呼び出す：新しいチャットの入力欄で@を入力し、候補の「プラグイン」から選んで依頼します。

Desktop onlyの機能はデスクトップアプリで使います。プラグインの導入だけでは、任意の操作を全部許可したことにはなりません。公式：プラグインの導入

チャット欄では、@ と / で呼び出す。

ChatGPT のチャット欄で@を入力すると、導入済みのプラグイン（と同梱のスキル）が候補に出ます。/を入力するとコマンド一覧が開き、有効なスキルもそこに並びます。Codex でも@でプラグインを、/の一覧または$スキル名でスキルを選べます。

/ 依頼文整理 この依頼を、分かりやすく整理して。（Codex では $依頼文整理）

@ GitHub このリポジトリのREADMEを要約して。

スキルプラグイン
ChatGPT（Chat / Work）/ の一覧から選ぶ（@ でも指定可）@ で指定
Codex/ の一覧 または $スキル名@ で指定（導入は Customize → Plugins）

候補から選ぶと使用対象を指定できます。名前を指定せず、依頼に応じて適した機能が選ばれる場合もあります。練習室では入力欄に / や @ を打って、候補を選ぶ操作を体験できます。出典：スキルの作成・導入・スラッシュコマンド・プラグイン（2026年9月29日確認）。画面の流れは2026年9月29日時点のWindows版ChatGPTデスクトップアプリの画面で確認しました。

05 / CODEX

作業場所と、任せる範囲を決める。

まずは作品フォルダを選択

Codexに切り替え、プロジェクト追加やフォルダ選択から、自分の作品フォルダを開きます。新しいタスクを作成し、そのフォルダが作業場所になっていることを確認します。

my-website/
├─ index.html
└─ css/
   └─ style.css

フォルダの選択は「どの作品を扱うか」の指定です。権限の選択は「どこまで操作を任せるか」の指定です。

承認を求める

作業領域内の読み書きや通常のコマンドは進められます。領域外へのアクセスやネットワーク利用など、境界を越える操作で承認を求めます。

代わりに承認

対象となる承認依頼を、レビュー用のエージェントが判断します。依頼内容や許可範囲を確認する仕組みで、すべての操作を無条件に許可する意味ではありません。

フルアクセス

ファイルやネットワークへの制限を広く解除します。何にアクセスする作業かを理解して選びましょう。初回の教材では「承認を求める」で練習できます。

06 / WORK TOGETHER

「何を、どう変えるか」を伝えよう。

そのまま試せる依頼文

# 目的
トップページの見出しを変えたいです。

# 変更内容
index.htmlのh1を
「はじめてのAI制作」にしてください。

# 条件
ほかの文章やレイアウトは変えないでください。
変更後に、変更箇所と確認結果を教えてください。
01　変更点を読む

完了メッセージだけでなく、差分（変更前と変更後）とブラウザ表示を確認します。

02　途中でも指示を直せる

意図がずれたら停止して、「色はそのままで」と具体的に補足しましょう。

03　Gitで区切りを残す

作業前後に変更を確認してコミット。AIの編集も、履歴があれば比較しやすくなります。
