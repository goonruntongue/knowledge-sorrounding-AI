02 / INSTALL

公式サイトから、はじめよう。

Windowsでも、まずはアプリのインストールから。
使える機能は、アカウント・プラン・組織の設定で変わります。

ChatGPT / Codex

  1. 公式ダウンロードでWindows用を選ぶ
  2. インストールしてChatGPTアカウントでログイン
  3. 切り替えメニューからCodexを選ぶ

旧版のChatGPT Classicとは表示や機能が異なります。

Claude / Claude Code

  1. 公式ダウンロードでPCに合うWindows用を選ぶ
  2. インストールしてClaudeアカウントでログイン
  3. Code（</>）を選び、追加セットアップがあれば案内に従う

Google Antigravity

  1. 公式ダウンロードを開く
  2. Antigravity 2.0のWindows用をインストール
  3. Googleアカウントでログインし、プロジェクトを作る

IDE版もあります。ここで紹介しているのはエージェント管理用の2.0です。

EXAMPLE: CHATGPT

ここからは、例として ChatGPT の使い方を紹介します。
モードの選び方 → スキルとプラグイン → 開発用の Codex の順に見ていきます。

Claude Code や Antigravity でも、基本の流れは同じです。

  • フォルダを選ぶ
  • 任せる範囲を決める
  • 依頼する
  • 変更を確認する

画面の名前や配置は製品ごとに違うので、使うときは各社の公式資料で確認しましょう。

04 / SKILLS & PLUGINS

いつもの手順と、使える道具を増やす。

SKILL

スキル＝作業のレシピ

「どの順番で、何を確かめ、どう仕上げるか」を何度でも使える形にしたもの。

例：文章を「目的 → 対象 → 依頼内容」の順に整理する。
  • 中心はSKILL.mdという指示ファイル
  • スキルだけでは外部アカウントにつながらない
PLUGIN

プラグイン＝追加機能のパッケージ

スキルや、外部サービスにつながる道具をまとめて追加する仕組み。

例：GitHubの情報を調べる道具と、作業手順を追加する。
  • 必要なときは外部アカウントを接続する
  • インストール・接続・依頼は別々の操作

スキルを導入する

  1. Customize → Skills を開く左端のアイコン列から開きます。
  2. 右上の「追加」を押すSkill Creator が入った新しいチャットが開きます。
  3. 覚えてほしい手順を説明して送信下の依頼文のように書きます。
  4. 「インストール済み」で確認内容と、どこで使えるかを確かめます。
Skill Creator
「依頼文整理」というスキルを作って。
このプロジェクトの依頼文を
目的・対象ファイル・変更内容・条件に整理して。
くわしく
  • チャット欄で@skill-creator、Codexでは$skill-creatorと呼ぶこともできます。
  • 一覧に見つからない場合は、アプリを再起動して確認します。
  • 配布されたスキルは、Codexで$skill-installerを呼び、スキル名や配布元のURLを伝えて導入できます。配布元から入れる場合も内容を確認しましょう。

公式：スキルの作成・導入

プラグインを導入する

  1. Customize → Plugins を開く一覧や検索で目的のものを探します。
  2. 説明を読んで「＋」で追加追加済みは「…」になり、Installed に並びます。
  3. 必要ならアカウントを接続ログイン先とアクセス範囲を確認します。
  4. チャット欄で「@」から呼び出す候補の「プラグイン」から選んで依頼します。
くわしく
  • 接続は、最初に使うときに求められる場合もあります。
  • Desktop only の機能はデスクトップアプリで使います。
  • プラグインを入れただけで、どんな操作も許可したことにはなりません。

公式：プラグインの導入

チャット欄では、@ と / で呼び出す。

@
プラグインを呼ぶ

導入済みのプラグイン（と同梱のスキル）が候補に出ます。

@ GitHub このリポジトリのREADMEを要約して。

/
スキルを呼ぶ

コマンド一覧が開き、有効なスキルも並びます。Codexでは$スキル名でも選べます。

/ 依頼文整理 この依頼を、分かりやすく整理して。

スキルプラグイン
ChatGPT（Chat / Work）/ の一覧から選ぶ（@ でも指定可）@ で指定
Codex/ の一覧 または $スキル名@ で指定（導入は Customize → Plugins）

名前を指定しなくても、依頼に合った機能が選ばれる場合があります。練習室では / や @ を打って、候補を選ぶ操作を体験できます。

出典：スキルの作成・導入・スラッシュコマンド・プラグイン（2026年9月29日確認）。画面の流れは2026年9月29日時点のWindows版ChatGPTデスクトップアプリで確認しました。

05 / CODEX

作業場所と、任せる範囲を決める。

フォルダは「どの作品を扱うか」、権限は「どこまで任せるか」の指定です。
この2つを決めてから依頼します。

  1. プロジェクトを選択入力欄の上のボタンを押す
  2. 新しいプロジェクト名前を付け、作品フォルダを追加
  3. フォルダを信頼自分の作品フォルダか確かめる
  4. 承認方法とモデル入力欄の下で選んで依頼へ
my-website/
├─ index.html
└─ css/
   └─ style.css

信頼すると、ChatGPTはこのフォルダのファイルを読み取り・編集・実行できるようになります。

承認を求める

外部ファイルの編集やネット利用は、毎回確認。作業フォルダ内の読み書きは進められます。

代わりに承認

安全でない可能性がある操作だけ確認。何でも許可する設定ではありません。

フルアクセス

ネットとPC上のすべてのファイルに制限なくアクセス。初回は「承認を求める」で練習しましょう。

カスタム（config.toml）

設定ファイルで決めた権限を使う、上級者向けの設定です。

06 / WORK TOGETHER

「何を、どう変えるか」を伝えよう。

そのまま試せる依頼文

# 目的
トップページの見出しを変えたいです。

# 変更内容
index.htmlのh1を
「はじめてのAI制作」にしてください。

# 条件
ほかの文章やレイアウトは変えないでください。
変更後に、変更箇所と確認結果を教えてください。
01　変更点を読む

完了メッセージだけでなく、差分とブラウザ表示を確認します。

02　途中でも指示を直せる

ずれたら止めて、「色はそのままで」と具体的に補足します。

03　Gitで区切りを残す

作業の前後でコミット。履歴があればAIの編集も比べやすくなります。
