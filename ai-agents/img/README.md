# 練習室のアイコン

- ChatGPT / Codex / Claude / Google の各マークは `ai-agents/` 直下の `ChatGPT-Logo.svg`・`Claude-ai-icon.svg`・`Google-gemini-icon.svg` を使用しています（リポジトリ所有者が配置）。Codex は ChatGPT アプリ内のモードのため ChatGPT のマークを使っています。
- `github.svg` は GitHub の公式マークで、Simple Icons（https://github.com/simple-icons/simple-icons 、CC0 1.0）から2026年9月28日に取得しました。商標は GitHub, Inc. に帰属します。
- `rail/` の左端アイコン（home / schedule / library / image / customize と各 `-clicked`、plugins、skill-badge）はリポジトリ所有者が `for-simulator/CodexDisplay-assets` に用意したSVGです（2026年9月29日に配置）。`rail/skill.svg` は同フォルダの `skills.svg` から立方体の部分だけを切り出したものです。
