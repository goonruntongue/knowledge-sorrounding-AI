SSH KEY / HANDS-ON

SSH鍵を作って、
サーバーへ登録する。

WindowsでEd25519鍵を作り、公開鍵だけをサーバーに登録する流れを、安全な練習画面で体験します。実際のPC・サーバー・アカウントは一切変更されません。

公開鍵と秘密鍵

公開鍵：サーバーへ登録してよい
秘密鍵：自分のPCから出さない

今回の鍵種別

Ed25519 を使います。FreeBSD 13.0の環境で使える、現行の標準的な選択です。鍵の種類はサーバー側の対応状況に従います。

✓ 公開鍵を登録しました。次回からこの鍵に対応する秘密鍵で認証できます。
秘密鍵を保管先へドラッグ： 秘密鍵はサーバーへ送らず、PCの %USERPROFILE%\.ssh\ に保管します。下の鍵をフォルダ内へドラッグして、保管場所を確認してください。
📁 C:\Users\あなた\.ssh\ （既定の安全な保存先）
🔐秘密鍵id_ed25519

この鍵をフォルダの中へドラッグ

✓ 秘密鍵をPC内に保管しました。秘密鍵はメール・チャット・GitHub・サーバーへ送らないでください。

補足：実際には ssh-keygen -t ed25519 をオプションなしで実行すると、鍵ははじめからこの %USERPROFILE%\.ssh\ に生成されます。この操作は「秘密鍵をどこで守るか」を確認するための練習です。

✅

SSH鍵設定の流れを完了しました

公開鍵はサーバーへ、秘密鍵はPC内へ。次に実際に接続するときは、秘密鍵を指定して認証します。

ssh -i ~/.ssh/id_ed25519 ユーザー名@ホスト名

ここまでの操作はすべて教材内のシミュレーションです。
