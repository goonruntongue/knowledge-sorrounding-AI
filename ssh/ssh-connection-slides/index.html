BEGINNER'S GUIDE / SSH

REMOTE CONNECTION

SSHで、離れたサーバーに安全につながる。

SSHは、手元のPCからサーバーへ暗号化された通り道をつくる仕組みです。ファイル操作やコマンド実行を、安全に行えます。

⌘あなたのPCコマンドを入力する場所
▣リモートサーバーWebサイトなどが動く場所

01 / 04

FIRST TIME SETUP

鍵を持っていないなら、最初に鍵ペアを作る。

サーバー登録だけ済んでいる状態から始める手順です。PC上で鍵を作り、公開鍵だけをサーバーの管理画面に登録します。

01 / GENERATE

PCで鍵を作る

Windows Terminal または PowerShell で鍵ペアを生成します。

ssh-keygen -t ed25519
AIへの依頼文例
SSH接続できるサーバーには登録済みですが、鍵はまだありません。Windowsで鍵を作るところから教えてください。
02 / REGISTER

公開鍵を登録

作成された 公開鍵 の内容を、サーバーのSSH公開鍵登録画面へ貼り付けます。

id_ed25519.pub
03 / KEEP SAFE

秘密鍵はPCに残す

秘密鍵 は送らず、共有せず、自分のPCだけに保管します。

id_ed25519

02 / 04

TRY IT / TERMINAL

ターミナルに、接続コマンドを打ち込んでみる。

下の入力欄をクリックし、例のコマンドを入力して Enter。本物の接続は行わない安全な練習です。

Terminal — SSH practice (offline)
PC: ssh
例：student@203.0.113.10 と入力して Enter

このデッキ内だけで動く練習です。実際の接続先は、サーバー契約先から案内された ユーザー名@ホスト名 を使います。

03 / 04

WRAP UP

作業後は、接続を閉じて鍵を守る。

SSHは便利な入口です。秘密鍵の扱いと、作業後の切断を習慣にしましょう。

✓ 秘密鍵は自分のPCだけに保管する
✓ 接続先・ユーザー名は契約先の案内で確認する
✓ 作業終了後はSSH接続を閉じる
TERMINALexit

この1語でサーバーとの接続を終了します。共有PCではターミナルも閉じます。

04 / 04

DETAIL / KEY PAIR

秘密鍵は送らない。持っていることだけを証明する。

サーバーに公開鍵を置き、PC内の秘密鍵で照合します。公開鍵だけではログインできません。

🔐

秘密鍵

PCの外へ出さない。 メール、チャット、GitHubなどへ置かない大切な鍵です。

🔑

公開鍵

サーバーに登録してよい。 正しい秘密鍵を持つ相手だけを受け入れるために使います。
