04 / WEB SITE BASICS

WEBサイトとは画面をつくるしくみ

WebサイトやWebアプリの見た目と動きは、主に HTML・CSS・JavaScript でできています。まずは「どのファイルが、何を担当するのか」から見ていきましょう。

01 / WEB PAGE PARTS

Webページを構成するもの

Webページは、ひとつのファイルだけで完結するとは限りません。素材と役割をフォルダに分けて置くと、AIに直してほしい場所も伝えやすくなります。

HTMLindex.html
CSSstyle.css
JSscript.js
MEDIAimages / video / audio

サイトフォルダの基本形

  • HTML：ページに何を書くかを決める
  • CSS：色・大きさ・配置など見た目を決める
  • JavaScript：クリックやアニメーションなど動きを決める
  • 画像・動画・音声：ページで使う素材をまとめる

最初は index.html を入口にして、そこからCSS・JavaScript・画像を読み込むと考えれば大丈夫です。

02 / THREE ROLES

HTML・CSS・JSは、それぞれ別の係

HTML

内容と骨組み

見出し、文章、画像、ボタンなど「ページに何があるか」を書きます。

<h1>見出し</h1>
CSS

見た目と配置

文字色、余白、丸み、横並びなど「どう見せるか」を書きます。

h1 { color: #ff0000; }
JS

動きと反応

クリックしたら開く、時間で変わるなど「どう反応するか」を書きます。

button.addEventListener(...)
AI

AIには「index.html の見出しを追加し、style.css で青くして、script.js にクリック時の動きを書いて」と、ファイル名と役割を一緒に伝えるのがコツです。

細かな暗記よりも、担当とつながりを理解すると指示が出しやすくなります。
